# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and entries are managed
with [changie](https://changie.dev): add one with `npm run changelog`. Unreleased
fragments live in `.changes/unreleased/` until they are batched into a dated
section; see [`RELEASE.md`](RELEASE.md).
